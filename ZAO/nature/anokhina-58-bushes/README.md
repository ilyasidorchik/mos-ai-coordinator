# Исчезли кустарники на Анохина, 58

Координаты: около 55.6589, 37.4706 (улица Академика Анохина перед ТЦ, дом 58).

Три кустарника перед торговым центром росли около 10 лет; в 2025 году исчезли. В кустах жили воробьи. На улице идёт комплексное благоустройство 2026 года.
