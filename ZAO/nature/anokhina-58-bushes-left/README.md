# Исчезли кустарники слева от входа на Анохина, 58

Координаты: около 55.6589, 37.4706 (улица Академика Анохина перед ТЦ, дом 58).

Слева от входа в торговый центр росли шесть кустарников; рядом — кейс про три куста справа: [anokhina-58-bushes](../anokhina-58-bushes/).
