Текст:
Уважаемое Правительство Москвы!

Москва уже многое сделала для цифровых сервисов: электронная приёмная, mos.ru, мобильные приложения. При этом подача обращения по-прежнему рассчитана в основном на человека за экраном: формы, капчи, ручной ввод адреса и текста.

В мире быстро развиваются AI-агенты — помощники, которые по запросу человека собирают факты, оформляют документы и взаимодействуют с сервисами через программные интерфейсы. Открытый стандарт для такого взаимодействия — MCP (Model Context Protocol): он позволяет подключать внешние системы к агентам безопасно и единообразно.

Прошу рассмотреть создание официального MCP-сервера электронной приёмной Правительства Москвы, через который авторизованный житель мог бы с помощью своего AI-агента:

— подать обращение в нужное ведомство,
— приложить фото и видеоматериалы,
— получить номер обращения.

Что станет лучше:

1. Удобство для жителей. Не нужно вручную заполнять длинные формы: человек описывает проблему своими словами, агент помогает структурировать обращение и отправить его по правилам сервиса. При этом обращение можно будет отправить не заходя на сайт, а из своего чата с AI-агентом.
2. Качество обращений. Агент может напомнить о координатах, фото, номере предыдущего ответа — ведомства получат более полные и понятные тексты, меньше уточнений «по кругу».
3. Доступность. Сервис станет проще для людей, которым трудно работать с интерфейсами: пожилых, слабовидящих, тех, кому удобнее говорить, а не печатать.
4. Современная цифровая инфраструктура. Москва сможет предложить официальный канал для AI-агентов вместо стихийных обходов через неофициальные скрипты и эмуляцию браузера.
5. Прозрачность и контроль. Официальный протокол позволяет задать правила аутентификации, согласия жителя, логирования и защиты персональных данных — то, чего нет у «серых» автоматизаций.
6. Экономия времени сторон. Житель тратит меньше времени на бюрократию; операторы получают более единообразные пакеты данных.
7. Город становится лучше. Чем проще дать обратную связь, тем больше реальных проблем доходит до ведомств вовремя — и тем быстрее приводят в порядок дороги, транспорт, дворы и сервисы.

Подача через MCP не заменяет веб-форму и приложение: это дополнительный канал для тех, кто уже пользуется AI-помощниками. Человек остаётся автором обращения и несёт ответственность за содержание; агент — только инструмент оформления и передачи.

Прошу:

1. Рассмотреть целесообразность разработки официального MCP-сервера (или иного программного интерфейса того же назначения, например API) для электронной приёмной.
2. Если идея поддерживается — сообщить, какое подразделение может вести проработку и на каком горизонте возможны пилот или ТЗ.
3. Если сейчас это не планируется — кратко пояснить причины и возможные альтернативы для программной подачи обращений жителями.

С уважением
житель Москвы
