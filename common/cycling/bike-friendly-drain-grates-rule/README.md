# Требование к безопасным для велосипедистов дождеприемным решеткам

Предложение внести в МГСН 1.02-02 обязательное требование о применении на проезжей части дождеприемных решеток с пазами, безопасными для движения велосипедистов.

## Текущий статус

По [Дептранс](dep-trans/) ответ пришёл от ДЖКХ: возражений у Мосводостока нет, диагональные пазы уже закладывают на веломаршрутах; часть про МГСН переслана в Депград. По ДЖКХ и Депграду ответы ещё ожидаются.
