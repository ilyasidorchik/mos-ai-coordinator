Велосветофор на перекрёстке Бесединского шоссе и Хордового проезда


Текст:
Уважаемый Департамент транспорта города Москвы!

Обращаюсь по вопросу безопасности велопереезда Хордового проезда при съезде с Бесединского шоссе в ЮВАО, напротив дома на улице Борисовские Пруды, 16к3, подъезд 2.

В этом месте размечен велопереезд (без пешеходного перехода). При этом автомобили, движущиеся с Хордового проезда, едут со скоростью 60 км/ч и не уступают дорогу велосипедистам несмотря на заранее установленный знак 1.24 «Пересечение с велосипедной дорожкой». В результате пересечение получается неочевидным и небезопасным: разметка есть, а фактический приоритет и поведение водителей ей не соответствуют.

Прошу рассмотреть меры, которые сделают велопереезд заметнее и предсказуемее для водителей, а пересечение — безопаснее для велосипедистов.

Возможные варианты решения:

1. Покрасить велопереезд красной краской, чтобы повысить его заметность.
2. Нанести разметку 1.13 «Уступи дорогу» на автодороге для автомобилей перед велопереездом.
3. Установить светофор по кнопке для велосипедиста, то есть сделать велопереезд регулируемым.
4. Заложить на будущее адаптивный светофор: автоматически включать зелёный велосипедистам при подъезде, обнаруживая велосипед заранее с помощью индукционных петель в асфальте.
5. Сделать подсветку велосипедистов на велопереезде.

Прошу провести обследование участка и сообщить, какое решение возможно реализовать в ближайшее время, а какое целесообразно заложить в проект на перспективу.
