# Помощник для подачи обращений на портале Мос-ру

Составлять вручную обращения в Правительство Москвы — долго. В современном мире есть более эффективный способ — с помощью нейросетей. Агент поможет создать нужные папочки, накидать черновик обращения, проверить опечатки, оттипографировать, переименовать и сжать фотографии и в будущем самостоятельно отправить обращение на портал.

Бонусом идёт система хранения обращений и ответов. Ответы ведомств переводятся из ПДФки в удобный для работы текстовый файл. Нейросети учитывают историю ответов, помогая создавать более эффективные обращения. 


## Как настроить

Нам нужен текстовый редактор с умным автодополнением и встроенным чатом. Самые популярные варианты:

- Cursor (самый удобный вариант)
- VS Code с расширением Copilot (от GitHub) и Codex (от ChatGPT)
— Windsurf с расширением Claude (от Anthropic)


## Как пользоваться

Открываем встроенный в редактор чат и пишем ему сообщения как своему ассистенту: он умеет гуглить и работать с файлами. Пример сообщения для создания обращения:

> Создай обращение в СВАО, что автобус 605 нарушил интервал движения на 5 минут такого-то числа на такой-то остановке. Спроси почему и попроси принять меры.

Дальше:
> Переименуй фото
> Сожми фото
> Исправь опечатки в тексте и оттипографируй его

Подаём обращение в Электронную приёмную:
https://mos.ru/feedback/reception/

Записываем номер обращения для последующего поиска и пишем в чате «Сохранись»

После ответа на обращение кладём PDF-файл ответа в папку `inbox/` и пишем агенту `@inbox` — он сам найдёт нужный кейс, перенесёт файл в `response/` и переведёт его в текстовый `response/response.md`. Можно по-прежнему класть PDF сразу в `response/` и вызвать «Расшифруй ответ» или `pdf to text`. Далее говорим «Сохранись».
